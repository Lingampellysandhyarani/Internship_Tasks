# Day 1 – SQL HackerRank Problem Solving

**Internship:** Innomatics Data Analytics Internship  
**Platform:** HackerRank

## Problem 1: Revising The Select Query
**HackerRank:** https://www.hackerrank.com/challenges/revising-the-select-query/problem

**Solution:**
SELECT *
FROM CITY
WHERE COUNTRYCODE = 'USA'
AND POPULATION >100000;

## Problem 2: Select All
**HackerRank:** https://www.hackerrank.com/challenges/select-all-sql/problem

**Solution:**
SELECT *
FROM CITY;

## Problem 3: Japanese Cities' Attributes
**HackerRank:** https://www.hackerrank.com/challenges/japanese-cities-attributes/problem
